# Ejecucion en EMU8086

## Archivos

- `main.asm`: punto de entrada y menu principal.
- `include/constantes.inc`: constantes compartidas.
- `include/macros.inc`: macros de presentacion.
- `include/datos.inc`: mensajes, buffers y variables.
- `include/entrada_salida.inc`: consola, validacion numerica y sonidos.
- `include/archivos.inc`: acceso a archivos DOS.
- `include/academico.inc`: registro, cifrado, promedio y reporte.

## Compilar y ejecutar

1. Abra `main.asm` en EMU8086 manteniendo la carpeta `include` junto al archivo.
2. Seleccione **Compile**. El origen usa `org 100h` y se genera como programa COM.
3. Ejecute el programa desde un directorio con permiso de escritura.
4. Use la opcion 1 para crear o anexar registros a `CALIF.TXT`.
5. Use la opcion 2 para regenerar `FINAL.XLS` y mostrar las estadisticas.
6. Use la opcion 3 para ver el reporte desde el programa.

Los nombres admiten hasta 50 caracteres y no pueden contener comas. Las notas
deben ser enteros entre 0 y 20. Los archivos se crean en el directorio de trabajo
de DOS usado por EMU8086.

## Formatos

`CALIF.TXT`:

```text
Nombre,Nota1,Nota2,Nota3
```

`FINAL.XLS` (texto CSV compatible con Excel):

```text
NombreCifrado,Nota1,Nota2,Nota3,Promedio,Estado
```

Ejemplo:

```text
Mxdq,15,18,16,16,APROBADO
```
